# Current validation scope — package only

This revision reuses the existing GeoMotion Thai implementation and resources. It changes activation, safe CLI boundaries, connection settings, installation instructions and packaging. No new images/icons, narration, sample clips or video frames are generated. No Google/media-generation service is contacted. No Blender/FFmpeg rendering, ASR model download or live voice audition is performed.

The current offline checks cover Python syntax/AST, JSON/YAML structure, required resources and relative documentation links, disabled-by-default service configuration, default refusal at production entry points, guarded callable production functions, installer dry-run destinations for the three local clients, text-only new-project templates for both aspect ratios, and both upload archive layouts/checksums. A regression test reproduces and rejects a loose top-level checksum file, the cause of the reported upload failure. The Claude wrapper is checked for `.claude-plugin/plugin.json` and `skills/geomotion-thai/SKILL.md`. See `package-validation.json` for the actual result generated for this revision.

Not tested in this revision: actual acceptance by the user's Claude upload UI, Claude CLI plugin loading/validation, authenticated Google AI Studio synthesis, live Gemini API models/voices/speech, emotional quality or consistency of a narrator, timing against real narration, current end-to-end media generation/rendering/decoding, or recognition/execution inside separately installed Claude Code and Antigravity clients. A client path documented from an official source is not a claim that its runtime was executed here.

Existing model/PNG/flag/font/reference assets are retained from earlier work; they are not regenerated in this revision. Their comparison notes and geographic limitations remain in the corresponding references. Previous video/render tests do not substitute for later testing of the changed production gates and live connections. A requested future clip must be researched, generated and inspected at production time before claiming it passed media acceptance.
